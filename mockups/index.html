Notes de Conversion Razor

Éléments marqués dans les maquettes :
  • <!-- LAYOUT START --> et <!-- LAYOUT END --> : Navbar et footer à extraire vers _Layout.cshtml
  • <!-- PARTIAL: _PokemonCard --> : Carte Pokémon à extraire vers une vue partielle
  • <!-- PARTIAL: _TrainerForm --> : Formulaire dresseur à extraire vers une vue partielle
  • <!-- FOREACH --> : Élément répété à convertir en boucle @foreach en Razor
  • <!-- DEMO ONLY, à supprimer --> : Blocs de démonstration à retirer en production
Noms des champs de formulaire :
  • Name : Nom du dresseur
  • Town : Ville d'origine
  • BadgeCount : Nombre de badges
  • Id : Identifiant (hidden field)
  • Ball : Type de Poké Ball (PokeBall, SuperBall, MasterBall)
  • trainerId : ID du dresseur (capture)
  • pokemonId : ID du Pokémon (capture)
Classes CSS de validation :
  • .input-validation-error : Appliqué automatiquement aux champs en erreur
  • .text-danger : Pour les messages d'erreur
