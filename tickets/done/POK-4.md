## Technology topic template
To ensure the cohesion behind the cursus, each topic covered must follow the same template.
This template will be used for all subjects covered by the table of content.

## Refined Template Structure

### 1. Overview & Introduction
- **What**: Brief description of the technology (1-2 paragraphs)
- **Why**: Why use this technology? What problems does it solve?
- **When**: When to use it (use cases)

### 2. Prerequisites
- Required prior knowledge
- Required tools/software that must be installed first
- Minimum system requirements (if applicable)

### 3. Core Concepts & Theory
- Key concepts explained in simple terms
- Important terminology/glossary
- Architecture overview (if applicable)
- Visual diagrams where helpful

### 4. Installation Guide
- Step-by-step installation instructions
- Different installation methods (if multiple exist)
- Platform-specific instructions (Windows/Mac/Linux)
- How to verify successful installation

### 5. Initial Setup & Configuration
- First-time configuration steps
- Configuration file structure (if applicable)
- Essential settings to configure
- Environment setup

### 6. Basic Usage
- Simple "Hello World" type example
- Most common use cases
- Step-by-step walkthrough with code examples
- Expected output/results

### 7. Practical Examples
- Real-world scenarios
- Progressive complexity (simple → intermediate)
- Code snippets with detailed explanations
- Best practices demonstrated

### 8. Common Patterns & Best Practices
- Recommended approaches
- Do's and Don'ts
- Code organization patterns
- Performance considerations

### 9. Troubleshooting & Common Issues
- Frequently encountered problems
- Error messages and solutions
- Debugging tips
- Where to get help

### 10. Additional Resources
- Official documentation links
- Recommended tutorials
- Community resources
- Next steps for learning

## Key Improvements
- Separated "Overview" from "Theory" - beginners need context before diving into concepts
- Added "Prerequisites" - crucial for newbies to know what they need first
- Split "Usage" into "Basic" and "Practical Examples" - progressive learning
- Added "Best Practices" - helps beginners learn the right way from the start
- Added "Troubleshooting" - newbies will encounter issues and need help
- Added "Additional Resources" - provides paths for continued learning
